# BVA Analysis for I18n

## Method: `setLocale`

- **TC1: Set locale to English** ( :white_check_mark: )
  - **State of the system**: I18n initialized, locale defaulted to English
  - **Expected output**: locale set to English
- **TC2: Set locale to French** ( :white_check_mark: )
  - **State of the system**: I18n initialized, locale defaulted to English
  - **Expected output**: locale set to French
- **TC3: Set locale to German** ( :white_check_mark: )
  - **State of the system**: I18n initialized, locale defaulted to English
  - **Expected output**: locale set to German

## Method: `t`

- **TC4: Unformatted text** ( :white_check_mark: )
  - **State of the system**: I18n initialized, locale defaulted to English, key exists in `messages.properties`
  - **Expected output**: Correct message outputted
- **TC5: Non-existent unformatted text** ( :white_check_mark: )
  - **State of the system**: I18n initialized, locale defaulted to English, key does not exist in `messages.properties`
  - **Expected output**: Error message returned in the format: `!{key_name}!`
- **TC6: Translated unformatted text** ( :white_check_mark: )
    - **State of the system**: I18n initialized, locale updated to French, key exists in `messages_fr.properties`
    - **Expected output**: Correct message outputted
- **TC7: Non-existent translated unformatted text** ( :white_check_mark: )
    - **State of the system**: I18n initialized, locale updated to French, key does not exist in `messages_fr.properties`
    - **Expected output**: Error message returned in the format: `!{key_name}!`
- **TC8: Unsupported language  text** ( :white_check_mark: )
    - **State of the system**: I18n initialized, locale updated to German, `messages_de.properties` does not exist, key exists in `messages.properties`
    - **Expected output**: Fallback to English message
- **TC9: Unsupported language non-existent unformatted text** ( :white_check_mark: )
    - **State of the system**: I18n initialized, locale updated to German, `messages_de.properties` does not exist, key does not exist in `messages_fr.properties`
    - **Expected output**: Error message returned in the format: `!{key_name}!`
- **TC10: Formatted text, one placeholder, one argument** ( :white_check_mark: )

  - **Expected output**: Correct message outputted
